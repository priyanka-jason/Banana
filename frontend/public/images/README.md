# UI assets

The four grocery images were created with built-in image generation using the
approved Home mockup as the reference. WebP files preserve transparency and
are sized for the product slots. Original PNGs are retained in
`frontend/design/product-assets/`.

Store identities use existing logo assets rather than code-drawn substitutes:

- Save-On-Foods: compact site icon served through Google's public favicon cache
  for saveonfoods.com; original horizontal mark from Wikimedia Commons.
- No Frills: https://upload.wikimedia.org/wikipedia/en/2/23/No_Frills_logo.svg
- Walmart: https://commons.wikimedia.org/wiki/File:Walmart_spark_(2025).svg
- Superstore: https://upload.wikimedia.org/wikipedia/en/b/bb/Real_Canadian_Superstore_logo.svg
  The compact `superstore-mark.svg` uses a viewBox focused on the existing symbol;
  its source geometry is unchanged.

Retailer names/logos identify the illustrative stores. The sample prices are
not supplied or verified by the retailers. Fonts are self-hosted from Fontsource
(DM Serif Display and DM Sans); interface icons use Phosphor's regular set.
